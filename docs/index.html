    About this model

    The same mixed-integer program as the Python/Pyomo version: maximize total demand plus a bonus for every covered census tract, subject to a charger budget and a minimum spacing between sites, over 2,000 candidate locations.

    It is solved exactly in your browser with the HiGHS solver (WebAssembly), so no server is involved.

    On the numbers: the Python code counts a tract as covered only if a site lies inside it. The paper uses a 0.5-mile radius and reports 72.3% of tracts and 78.5% of the population. The tiles above always show the 0.5-mile figures; the saved 50-site solution scores about 76% / 80% on this demo's 206 tracts.
