Layers

Runs the same mixed-integer model as the Python/Pyomo version (maximize demand + coverage bonus, subject to a charger budget and minimum spacing) on 2,000 candidate sites. It is solved exactly in your browser with the HiGHS solver (WebAssembly), so no server is involved. Hover a pin for the street name, click for coordinates.
